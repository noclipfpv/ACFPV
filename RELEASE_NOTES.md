## AC FPV PRO v1.1.0

Built on the FPV Drone mod for Assetto Corsa by **sug44**. Additions by **NoclipFPV**. Published with sug44's agreement, MIT license.

**New:** Arm / Disarm, axis keybinds for radio switches, Dual OP with Ronin follow modes and gimbal
track recording, Record tab (Replay FPV / Replay gimbal, Gyroflow style stabilization, focal length),
Inspire mode (Tripod / Normal / Sport), Simulation value (turbulence and prop wash), flight
save / load, unified Help tab.

**Install:** download `FpvDrone.zip` and install it with Content Manager (or extract the `FpvDrone`
folder into `assettocorsa/apps/lua/`). Requires CSP 0.3.0+.
